# Sound effects: sources and licences

Every file in this folder is a real recording (no synthesized clicks). All files were trimmed (the hit sits at 0 ms or at the `lead` point listed in `src/lib/sfx.tsx`), normalised to −1 dBFS and resampled to 48 kHz. Edited versions keep the licence of their source.

The original selection, cleaning and measuring of the base set was done by Jasper Kallfelz for his [shortform-edit-kit](https://github.com/JasperKallfelz/shortform-edit-kit). This repo adds the files marked *added*.

## Adding a sound

Only add files whose licence allows redistribution and commercial use without attribution (CC0, public domain, or an explicit equivalent). Add a row here, trim and normalise the file, then measure `len`, `lead` and `loud` and add it to `SOUNDS` in `src/lib/sfx.tsx`. See [docs/sound-and-music.md](../../../docs/sound-and-music.md#adding-a-sound).
